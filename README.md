# PharmaCare — نسخة العرض الجامعي

واجهة تعليمية بالإنجليزية افتراضيًا، مع التاميلية والعربية من قائمة اللغة أعلى الصفحة.

## التشغيل

- افتح `index.html` لتصفح الوظائف التي لا تحتاج إلى كاميرا أو اتصال خارجي.
- يمكن تثبيت التطبيق كتطبيق ويب PWA بعد نشر الملفات على موقع HTTPS. على Android استخدم قائمة المتصفح واختر «تثبيت التطبيق»؛ وعلى iPhone/iPad استخدم Safari ثم «مشاركة» ← «إضافة إلى الشاشة الرئيسية». يظهر زر التثبيت داخل التطبيق عندما يتيح المتصفح ذلك.
- يمكن تجربة التثبيت محليًا على `localhost`، لكن لا يمكن تثبيت نسخة ZIP مباشرة، كما أن الكاميرا والتثبيت لا يعملان عند فتح الصفحة كملف محلي.
- يتطلب مسح الباركود متصفحًا يدعم `BarcodeDetector`، وإذن الكاميرا، وتشغيل التطبيق على HTTPS أو localhost.
- تُرسل عمليات بحث الخريطة إلى Google Maps. لا يُطلب الموقع الدقيق إلا عند الضغط على «موقعي».

## حدود مهمة

- مكتبة المشروع التعليمية واسعة، لكن تفاصيل سجلاتها ليست كلها موثقة بشكل مستقل. تعرض صفحة الدواء المعلومات المفقودة بوصفها غير متوفرة، وتربط إلى معلومات CDSCO وأسعار NPPA الرسمية.
- ماسح الباركود يقرأ الرمز. لا تتضمن هذه النسخة قاعدة GTIN هندية موثوقة تربط الرمز بكل عبوة؛ لذلك لا تؤكد هوية المنتج عند عدم وجود تطابق موثق. سجل نقوش الأقراص الموثق غير مضاف بعد.
- يمكن الرجوع إلى [سجل الأدوية الحكومي الهندي (ABDM)](https://drugregistry.abdm.gov.in/) وإلى [GS1 India DataKart](https://www.gs1india.org/services/gtin-validation). لم تُدمج واجهة API لأي منهما في هذه النسخة.
- فاحص الأعراض أداة تعليمية تجريبية قائمة على قواعد بسيطة، ولا يشخص ولا يقترح أدوية.
- صفحة الحساب تحفظ الصورة المصغرة، وجهات اتصال الطوارئ، والتفضيلات والملاحظات محليًا في المتصفح دون تشفير. استخدم بيانات تجريبية فقط، ويمكنك تصديرها أو حذفها من الصفحة.
- أزرار ربط Google وApple والبريد تعرض حالة تجريبية فقط؛ لا يوجد تسجيل دخول فعلي أو اتصال بهذه الخدمات. تذكيرات الحساب والوحدات إعدادات عرض محفوظة، وليست خدمة تذكير أو تحويل وحدات تلقائية على مستوى التطبيق.
